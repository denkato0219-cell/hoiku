        通知（ntfy）

        1. ntfy アプリを開いて右上の「＋」をタップ
        2. Topic に下の名前を貼り付けて「Subscribe」（サーバーは ntfy.sh のまま）
        3. 「テスト通知を送る」を押して、ロック画面に届くか確認

        トピック名を知っている人は通知を読めるので、推測されにくい名前を自動で作っています。iPhoneの「設定 → 通知 → ntfy」でサウンドをオンにし、集中モードを使う場合は ntfy を許可してください。

        目標

        どのくらい勉強すればいい？

        合格まで独学で300〜600時間、期間で半年〜1年がよく言われる目安です。初学者は400時間前後を目標にすると計画が立てやすくなります。
        1日の目安平日1〜2時間、休日3〜4時間。毎日少しでも触れるほうが、週末にまとめてやるより定着します。
        1日の上限6時間。それ以上は集中が落ちやすいので、このアプリは6時間で打ち切ります。

        時間に合わせた組み方（おまかせ時）

        1時間未満20〜30分を1〜2本。思い出す練習が一番効くので、過去問.comを優先します（初めての科目だけ動画から）。
        1〜3時間25分集中＋5分休憩。4本ごとに15分休憩（ポモドーロ）。
        3時間以上50分集中＋10分休憩。2本ごとに20分休憩。1本の中で「動画→テキスト」「過去問.com→過去問テキスト」をまとめて行います。
        最初と最後最初の5〜10分は前回の×・★の解き直し。最後に半端な時間が残ったら、その日の間違いノートの見返しに使います。

        時期ごとのバランス

        試験まで3か月以上インプット多め：動画 → テキスト → 過去問.com → 過去問テキスト
        1〜3か月アウトプット多め：テキスト → 過去問.com → 過去問テキスト → 過去問.com
        1か月を切ったら過去問中心。初めて手をつける科目だけ動画から入ります。

        科目の選び方（おまかせ時）

        正答率が6割未満の科目、しばらく触れていない科目、まだ手をつけていない科目ほど先に入ります。保育士試験は全科目6割以上で合格なので、苦手を残さないことを優先しています。
